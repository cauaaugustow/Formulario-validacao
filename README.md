# Validação de Formulário 📋

Um projeto front-end focado na implementação de validação de dados de formulário no lado do cliente (client-side), garantindo que as informações inseridas pelo usuário estejam corretas antes de serem enviadas.

## 🚀 Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias:

*   **HTML5** (31.3%) - Estruturação do formulário.
*   **CSS3** (23.2%) - Estilização e feedback visual de erros/sucesso.
*   **JavaScript** (45.5%) - Lógica de validação e manipulação do DOM.

## 📁 Estrutura do Projeto

*   `index.html`: Arquivo principal contendo a estrutura da página.
*   `assets/`: Pasta destinada a armazenar os arquivos de estilo (`.css`), scripts de validação (`.js`) e possíveis mídias.
